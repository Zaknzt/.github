# Zaknzt GitHub Defaults

This repository contains shared community-health and contribution defaults for Zaknzt repositories.

These files provide common issue, pull-request, support, security, and contribution guidance for Final Fantasy XI / Windower projects unless a repository supplies its own project-specific version.

## Scope

This repository contains repository-management documentation only. It is not an implementation source for any FFXI addon, GearSwap file, inventory model, packet capture, or private development artifact.

Individual projects retain their own source, versioning, testing, release, attribution, and licensing requirements.
