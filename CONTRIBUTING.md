# Contributing

Thanks for helping improve Zaknzt FFXI / Windower projects.

## Before submitting

Please:
- identify the addon or project and version;
- describe what you expected and what actually happened;
- provide clear reproduction steps;
- keep changes narrowly scoped;
- include tests or live-validation notes when practical;
- identify any third-party source or upstream project involved.

Do not submit:
- passwords, API keys, tokens, or account credentials;
- unrelated personal information;
- private filesystem paths unless necessary and sanitized;
- private inventory/account exports unless the project explicitly requests them;
- copyrighted third-party source that cannot legally be redistributed.

## Pull requests

A pull request should explain:
- what changed;
- why the change is needed;
- how it was tested;
- compatibility or regression risks;
- any source/provenance or licensing considerations.

Project-specific instructions override these defaults when present.
