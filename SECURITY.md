# Security and Sensitive Information

Most repositories under this account are game addons, GearSwap code, compatibility work, or development tooling rather than security-sensitive services.

If you discover an issue that could expose credentials, private account information, personal data, or other sensitive material, do not post the sensitive information publicly.

Instead, open the smallest possible report without the secret itself, or contact the repository owner privately through an appropriate established channel.

Never include passwords, API keys, authentication tokens, session secrets, or unnecessary personal information in issues, pull requests, logs, screenshots, or attachments.
